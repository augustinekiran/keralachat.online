# Node.js SQLite Chat Application

A real-time chat app built with Node.js, Express, Socket.IO, and SQLite.

Features:
- Username and gender form before joining
- Public chat room by default
- Online users list in the sidebar
- Private chat when you click another online user
- SQLite database for storing users and messages

## Setup

```bash
npm install
```

## Run

```bash
npm start
```

Then open:

```text
http://localhost:3002
```

If port 3002 is unavailable, set a different port:

```bash
PORT=4000 npm start
```
